# 🍽 RestauManager

Application web de gestion de restaurant — Full Stack React + Node.js + MySQL

## 📋 Présentation

RestauManager est une application web permettant de gérer les activités d'un restaurant :
- Enregistrement des commandes clients (interface employé)
- Gestion du menu, des achats, du stock et des bénéfices (interface patron)
- Tableau de bord avec graphiques et indicateurs en temps réel

## 🚀 Stack technique

| Couche | Technologie |
|--------|------------|
| Frontend | React 19 + Tailwind CSS v4 + Vite |
| Routage | React Router v7 |
| État serveur | TanStack Query v5 |
| Graphiques | Recharts |
| Backend | Node.js + Express.js |
| Base de données | MySQL (XAMPP) |
| ORM | Prisma 5 |
| Auth | JWT + bcryptjs |
